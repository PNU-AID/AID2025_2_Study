순차 데이터(Sequence Data)란?

순서가 의미를 갖는 데이터

예시:
텍스트(문장), 시계열 데이터

특징:
데이터를 독립된 샘플로 취급할 수 없다

과거 입력이 현재 의미를 바꾼다




기존 피드포워드 신경망(완전연결층)의 한계

기존 피드포워드 신경망으로 순차 데이터를 처리하면 입력의 순서 고려 X

-->순차 데이터 처리 불가

결론: 순차데이터 처리에는
이전 정보가 다음 입력 처리에 영향 미치는 구조가 필요


RNN은 순차데이터를 처리하기 위해 이전 타임스텝의 은닉 상태(h)를 다음 타임스텝으로 전달하는 구조를 가진다.





RNN을 이루는 기본 단위 – 셀(cell)과 은닉 상태(hidden state)

셀(Cell)

순환층에서 반복해서 사용되는 계산 블록을 셀이라고 부름.일반적인 인공 신경망과 마찬가지로 셀 안에는 여러 개의 뉴런이 있음.


은닉 상태(hidden state, h)

셀의 출력 중, 다음 타임스텝에서 ‘기억’으로 다시 사용되는 값을 은닉 상태(hidden state) 라고 부름.

이 은닉 상태 h는 지금까지 들어온 모든 입력 정보를 요약해서 압축한 내부 메모리 역할.


a b c d e



입력 x(t)과 이전 은닉상태 h(t−1)을 함께 사용하여
새로운 은닉상태 h(t) 생성:

h_t = \tanh(W_x x_t + W_h h_{t-1} + b)



✔ RNN의 작동 원리

1. t=1에서 x₁ 입력


2. 출력된 h₁이 다음 입력 x₂ 처리에 함께 사용 → h₂ 생성


3. 계속 반복


4. 마지막 은닉 상태 hₙ을 최종 출력에 사용하거나
모든 h를 사용



활성화 함수 : 뉴런 출력에 비선형성을 부여하는 함수, 신경망이 복잡한 패턴을 학습하게 함

RNN에서는 주로 하이퍼볼릭탄젠트 사용(tanH)


RNN의 한계점:장기 의존성 문제 (Long-term dependency)

시간이 멀리 떨어진 정보는 전달될수록 영향력이 급격히 사라짐


계산 비효율성: 단계별 순차 계산, 병렬 처리 어려움



이 문제를 해결하기 위해 고안된 것이
LSTM(Long Short-Term Memory)
GRU(Gated Recurrent Unit)


LSTM의 작동 원리와 구조

LSTM은 RNN의 장기 의존성 문제를 해결하기 위해
게이트를 도입한 구조.

핵심 - 셀 상태(cell state, cₜ), 과거 정보를 “필요한 만큼만” 유지·삭제하는 역할


LSTM을 구성하는 3개의 게이트

1. 입력 게이트 (Input gate)
현재 정보를 얼마나 저장할지 결정


2. 삭제(망각) 개이트 (Forget gate)
과거 정보를 얼마나 버릴지 결정


3. 출력 게이트 (Output gate)
현재 상태 중 얼마를 출력할지 결정




LSTM의 작동 흐름

1. 현재 입력 xₜ와 이전 은닉상태 hₜ₋₁을 이용해 삭제 게이트 fₜ, 입력 게이트 iₜ, 후보 벡터 gₜ를 계산

2. 새로운 셀 상태 cₜ 계산

c_t = f_t \cdot c_{t-1} + i_t \cdot g_t

3. 출력 게이트 oₜ 계산 후 새로운 은닉상태 hₜ 생성



LSTM의 효과

RNN은 시간에 따라 정보가 빠르게 소실, LSTM은 셀 상태를 통해 멀리 떨어진 과거 정보도 안정적으로 전달




GRU는 LSTM을 더 단순하게 만든 버전
게이트 수를 줄여 계산량 감소, 속도 증가


GRU의 두 게이트

1. 업데이트 게이트 (Update gate), 과거 정보 유지/업데이트 비율 결정
(LSTM의 입력 게이트 + 삭제게이트 기능을 합친 형태)


2. 리셋 게이트 (Reset gate)
새 정보를 만들 때 과거 정보를 얼마나 반영할지 결정



GRU의 특징: 셀 상태(c)가 없음, 은닉 상태(h)가 모든 정보를 갖고 순환
구조 단순화 ---> LSTM보다 빠르지만 성능은 LSTM과 큰 차이가 없는 경우가 많다

과제






RNN: 순차 의존성은 잘 모델링하지만 기울기 소실, 폭발->장기 기억 실패라는 치명적 한계를 가짐.


LSTM: RNN의 장기 의존성 문제를 게이트 구조로 해결했지만 연산량이 크고 병렬화가 어려움.

----------------------------???
Attention: RNN/LSTM의 병렬화문제를 가중치 집중으로 보완했으나 기본 구조만으로는 독립 모델이 아님.

Transformer: 순환 구조를 제거해 병렬 처리와 장기 의존성 문제를 동시에 해결했지만 연산량이 큼.

BERT: Transformer를 기반으로 양방향 문맥 이해를 완성했지만 사전학습 비용과 메모리 사용량이 매우 큼.
