# 과제

### 딥러닝 모델(RNN, LSTM, Attention, BERT, Transformer)의 개념 공통점과 차이점 한줄 정리 (문제점-보완 위주로)

딥러닝 모델의 공통점 : 시퀀스의 의미를 잘 이해하기 위해 과거 정보를 유지하거나 중요한 부분에 가중치를 두는 방식이다.

**RNN**에서 긴 시퀀스에서 정보가 사라지는 장기 의존성 문제를 가지기 때문에 이를 보완하기 위해  필요한 정보는 유지, 불필요한 정보는 삭제하는 게이트 구조를 도입해 장기 기억 가능하게 하는 **LSTM**이 등장함.

하지만 여전히 RNN/LSTM은 순차적으로 데이터를 처리해 기억 범위에 한계가 있어 병렬적 데이터 처리로 전체 시퀀스를 한번에 보고 중요한 데이터를 직접 선택하는 **Attention** 이라는 연산 방식이 등장하게됨. **Transformer**는 attention연산 방식을 이용한 모델로, RNN구조를 제거하고 self-attention( 현재 단어가 문장 안의 어떤 단어에 집중해야 하는지 계산)을 여러 층 쌓아 전체 시퀀스에 대해 한번에 병렬 처리하도록 한다.

Transformer는 단방향 모델로 문장 전체 의미를 깊게 이해하지 못하는 한계를 가지고 있어 이를 보완하기 위해 **BERT**라는 양방향 self-attention 모델이 등장해 전체 문맥을 이해할 수 있게 됨.
